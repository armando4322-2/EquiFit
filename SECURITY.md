# Seguridad

## Reportar una vulnerabilidad

Si encuentras un problema de seguridad o de privacidad en EquiFit, **no abras un issue público**.
Usa la opción **Report a vulnerability** de la pestaña *Security* de este repositorio
(reporte privado de GitHub). Respondemos en un máximo de 5 días hábiles.

## Alcance

- La demo pública trabaja **solo con datos simulados** y no acepta archivos.
- Este repositorio **no contiene datos de participantes**. Si ves algo que parezca un dato real, repórtalo.

## Prácticas del equipo

- Verificación en dos pasos en las cuentas de GitHub y en la cuenta institucional donde viven los datos.
- Ningún token, contraseña o llave se guarda en el código ni se comparte por chat.
- Los datos de campo se analizan en una copia local y se borran al cierre del proyecto.
